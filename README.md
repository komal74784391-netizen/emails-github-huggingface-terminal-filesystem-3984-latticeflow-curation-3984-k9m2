# latticeflow-curation

Reference implementation for *LatticeFlow: Constraint-Guided Data Curation*
(NeurIPS 2025 Datasets & Benchmarks).

Released under the MIT license. The curation pipeline, the constraint solver and
the benchmark configs are included.

## Layout

- `src/latticeflow/` — curation pipeline
- `configs/` — run configurations
- `experiments/` — benchmark drivers
- `data/` — pointers to LatticeBench
